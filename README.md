# Digital Logic Sim — Apple Silicon macOS Build

An unofficial Apple Silicon/ARM64 macOS build of Sebastian Lague's
Digital Logic Sim.

## The Screen Aspect ratio fix

The aspect ratio fix changes the default UI aspect ratio dynamically,
making fullscreen display correctly on Macs.
